# Shared calendars

- Mode: Operate. Same-account planning across PC/Mac/phone; invite specific people to display or edit a chosen calendar.
- Preserve: approved sage/paper palette, Figma outlined icons, flat rows, existing protected drawers and phone touch sizing.
- Scope: Settings sync controls/conflict review; calendar list, recipient inbox, invite form, custom event permissions, event editing and revocation. Sharing needs sign-in; personal uploads need explicit opt-in.
- Truth: invitations are in-app with an optional copied link, not automatically emailed. Published deadlines are selected snapshots. Provider OAuth is a separate follow-up.
- Evidence: `outputs/Sync-Sharing-0.12.0.md`, live rollback SQL suite, `tests/cloud-sync.test.mjs`, `tests/sharing-browser.cjs`.
