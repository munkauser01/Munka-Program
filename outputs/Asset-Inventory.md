# Asset inventory

`assets/munka.png` is an extraction of the existing hanging monkey emblem from the user-supplied `Munka_Final_Project_Filled.pptx`, embedded image `ppt/media/image-1-1.png`. The source image is 1672 × 941; extraction bounds are x=64, y=44, x2=247, y2=226. No generative redraw was performed. Source provenance is embedded in the PNG metadata. `assets/munka.ico` is the Windows icon derived from that same extraction.

The original artwork is raster and has limited small-icon detail. A higher-resolution standalone original would improve final release branding. The app uses muted olive/sage, warm light surfaces, charcoal text, and the original name. Navigation icons are simple consistent geometric SVG paths, not substitutes for the logo.

The original presentation and PDF remain in the user's Downloads directory and are not copied wholesale into the repository. Their marketing statements, sample campaigns, social account handles, and pricing ideas are not presented as operational product facts.
